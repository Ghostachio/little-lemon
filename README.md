# 🍋 Little Lemon

**Little Lemon** is a **Coursera project** built with **React** to practice building interactive web applications. This project focuses on **React fundamentals**, such as components, state management, and event handling.

---

## 🔹 Project Overview
This project demonstrates how to:  
- Build **reusable React components**  
- Manage state using **React Hooks** (`useState`, `useEffect`)  
- Handle **user interactions** like form submissions  
- Structure a React project in a **clean and organized way**

---

## 🔹 Features
- ✅ Functional components with **React Hooks**  
- ✅ Simple form handling and validation  
- ✅ Dynamic rendering of content based on state  
- ✅ Modular and organized code structure  

---

## 🔹 Purpose
The project helped me :
- Understand **React fundamentals**  
- Practice **component creation and state management**  
- Handle **events and dynamic updates** in a React app
